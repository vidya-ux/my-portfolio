# Vidyashree 3D Portfolio — Frontend Only

There is **no backend, database, or API server**. This is a frontend-only React portfolio.

## Run on Windows / VS Code
1. Extract the ZIP.
2. Open the `vidyashree-3d-portfolio` folder in VS Code. It must directly contain `package.json`.
3. Open Terminal and run:
   ```powershell
   dir
   npm install
   npm run dev
   ```
4. Open the localhost URL printed by Vite (usually http://localhost:5173).

## Production build
```powershell
npm run build
```
Deploy the generated `dist` folder to Netlify, Vercel, or GitHub Pages.

## Personalize
In `src/main.jsx`, replace `your.email@example.com`, the sample LinkedIn and GitHub URLs, and any project links/placeholders before publishing. Review project descriptions for accuracy.

Requires Node.js 18+ (Node.js 20 LTS recommended).
